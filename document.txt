FAST API:

1. Isolate the Package using Environment:
  -command - python -m venv myenv
  -Activate Environment - myenv/Scripts/activate.bat
  -Deactivate Environment - deactivate
2. Fast API dependency - pip install fastapi uvicorn(webserver)
3. Running the app - uvicorn main:app --reload
4. pydantic - Data Validation - built in comes from uvicorn pakcage itself.
5. DB - SQLAlchemy - python sql toolkit and object relational mapper.
6. DB - pip install sqlalchemy psycopg2
7. model_dump - give us a dictionary. ** is unpacking option
8. FastAPI itself having the dependency injection concept.




Project Structure:


| Layer             | Purpose                                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------------------- |
| **core/**         | Environment config, DB setup (SQLAlchemy / async engine), logging, and security utilities.                    |
| **api/**          | Request/response layer (FastAPI routers, endpoints, and dependency injections).                               |
| **models/**       | SQLAlchemy ORM models or Pydantic Base models for database schema.                                            |
| **schemas/**      | Pydantic models for input/output validation (used in API endpoints).                                          |
| **repositories/** | Data access logic, separated for testability (DAO pattern).                                                   |
| **services/**     | Business logic that uses repositories or legacy services.                                                     |
| **legacy/**       | Old-style modules (e.g., raw SQL, non-async functions, or procedural scripts). This allows gradual migration. |
| **utils/**        | Shared helpers like exceptions, pagination, or formatters.                                                    |
| **tests/**        | Pytest-based unit and integration tests.                                                                      |
| **alembic/**      | Database migrations for SQLAlchemy.                                                                           |
